Frequently Asked Questions

Why is authorization required?

Microsoft Entra ID requires every customer tenant to explicitly authorize third-party multi-tenant applications. This authorization creates the Enterprise Application that Gordon uses to access tenant resources.

Do I need to create an App Registration?

No.

Gordon uses an App Registration managed by EOS Solutions. Customers only need to authorize the application once.

Is this required every time?

No.

This is a one-time operation per tenant. After authorization the Enterprise Application remains available in the tenant.

Are any Business Central Admin permissions granted?

No.

This process does not grant Business Central Admin Center permissions and does not require AdminCenter.ReadWrite.All.
